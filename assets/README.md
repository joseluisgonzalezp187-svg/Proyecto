# Assets

Coloca aquí los iconos de la app. Puedes generarlos automáticamente con:

```bash
npx expo prebuild --clean
```

O copia los assets por defecto desde un proyecto Expo:

```bash
npx create-expo-app@latest _temp --template blank
# Copia _temp/assets/* a esta carpeta
```

Archivos esperados por `app.config.ts`:

- `icon.png` (1024×1024)
- `splash-icon.png`
- `adaptive-icon.png` (Android)
- `favicon.png` (web)
